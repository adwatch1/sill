Politique de confidentialité

Dernière mise à jour : 25 septembre 2026

Sill Note est une application de notes pour Windows, conçue pour garder vos notes sur votre propre ordinateur. Cette politique explique précisément ce que Sill Note fait et ne fait pas de vos données.

En bref

  • Sill Note n’a ni compte, ni synchronisation cloud, ni statistiques, ni publicité, ni pistage.
  • Vos notes, images, audios et paramètres sont stockés uniquement sur votre ordinateur.
  • Sill Note ne se connecte à Internet que dans un seul cas, décrit ci-dessous, et vous pouvez le désactiver.

Données stockées sur votre ordinateur

Vos notes, les images et fichiers audio ajoutés, vos enregistrements vocaux et vos paramètres sont enregistrés dans le dossier de Sill Note de votre profil Windows. Le développeur ne les reçoit jamais. Ouvrez ce dossier via Paramètres → Dossier des notes. Si vous désinstallez la version Microsoft Store, Windows supprime ce dossier : copiez-le d’abord pour garder vos notes.

Aperçus de liens YouTube (seul usage réseau)

Quand vous collez ou déposez un lien YouTube dans une note, Sill Note télécharge une fois par vidéo la miniature depuis i.ytimg.com ainsi que le titre et le nom de la chaîne depuis youtube.com/oembed, puis les enregistre localement. Ces requêtes vont directement de votre ordinateur vers YouTube (Google), qui reçoit votre adresse IP et l’identifiant de la vidéo, comme pour toute requête web. Voir la politique de confidentialité de Google. Aucun contenu de note n’est envoyé. Désactivable dans Paramètres → Confidentialité → Aperçus de liens.

Micro

Sill Note utilise le micro uniquement pendant l’enregistrement d’une note vocale. L’enregistrement est sauvegardé comme fichier sur votre ordinateur et n’est jamais envoyé. Le micro est libéré dès que l’enregistrement s’arrête, est annulé ou que le panneau se ferme.

Dons

Le bouton « Offrez-moi un café » ouvre buymeacoffee.com/stilless dans votre navigateur. Les paiements sont gérés par Buy Me a Coffee selon sa propre politique de confidentialité. Sill Note ne traite aucune donnée de paiement.

Enfants

Sill Note ne collecte aucune donnée personnelle, y compris auprès des enfants.

Modifications

Si cette politique change, la nouvelle version sera publiée sur cette page avec une nouvelle date.
