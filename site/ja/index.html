メモを、画面の端に。

マウスを画面の右端に動かすと、メモがすっと現れます。離れれば、すっと消えます。Windows 用・無料。

Sill Note · 無料 · Windows 10 / 11 · アカウント不要 · v1.3.0

1.3 の新機能

画面共有のときは見えません。

スイッチをひとつオンにするだけで、Sill Note は画面録画、画面共有、スクリーンショットから消えます — Zoom、Teams、Discord、OBS。自分の画面ではいつもどおり表示されるので、通話中でもノートは手元にあります。

設定 → プライバシー → 画面共有で非表示。Windows 10（バージョン 2004）以降で動作します。カメラやキャプチャーボードで撮られた映像からは隠せません。

新機能 · 不透明度

向こうが透けて見える。

パネルの背景を 60%〜100% の間で透明にできます。文字や画像、ボタンはくっきりしたまま、下にあるものが少しだけ見えます。設定 → 外観 → 不透明度。

新機能 · 集中

一覧を隠して、ノートを広く。

左上のサイドバーボタンをクリックするとノート一覧がすっと隠れ、ノートがパネル全体に広がります。もう一度クリックすれば元に戻ります。

メディア

画像も、音声も、YouTube も。ひとつのメモに。

画像をドラッグ、音声ファイルをドロップ、YouTube のリンクを貼り付け。すべてテキストの隣、メモの中に収まります。

ボイスメモ

話すだけ。もう保存済み。

ワンクリックで録音開始、波形がリアルタイムで動きます。録音中にマイクの切り替えも可能。止めた瞬間にマイクはオフになります。

整理

2 段のタブ。カラーで。

上にトピック、左にメモ。色分け、名前の変更、並べ替えも自由自在。ライトとダークのテーマ付き。

プライバシー

あなたのメモは、あなただけのもの。

アカウントもクラウドも追跡もなし。すべてあなたのパソコンに保存されます。プライバシーポリシーを読む

知っておくと便利なこと

「Windows によって PC が保護されました」と表示される

直接ダウンロード版はまだ署名されていないため、初回のみ警告が表示されます。詳細情報 → 実行 をクリックしてください。今後公開予定の Microsoft Store 版は Microsoft の署名付きで、この警告は表示されません。

どうやって開くの？

マウスを画面右端の中央に置くか、Ctrl + Alt + N を押します。ショートカットは設定で変更できます。

インターネットに接続しますか？

YouTube のリンクを貼り付けたときだけです。動画のサムネイルとタイトルを一度だけダウンロードします。設定 → プライバシーでオフにできます。

どのファイルをダウンロードすればいいですか？

ほとんどの方はWindows 版をダウンロードで大丈夫です。管理者権限不要のインストーラーで、スタートメニューに Sill Note が追加されます。インストーラー（ZIP）は同じファイルを圧縮したもので、ブラウザーやメールが .exe をブロックする場合に便利です。ポータブル版はインストール不要。ZIP を好きなフォルダーに展開し、Sill.exe をダブルクリックするだけです。どれを使ってもメモは同じ場所に保存されます。

Sill Note が実際に何をしているか確認できますか？

はい。ソースコードはすべて GitHub で公開されており、アプリが何をしているかを誰でも確認できます。隠れた通信、追跡、バックグラウンドでのアップロードはありません。インターネットに接続するのは、任意の YouTube プレビューのときだけです。Microsoft Store 版は公開前に Microsoft の審査も受けます。

Sill Note を応援する

Sill Note は無料です。広告なし、アカウント不要、メモがパソコンの外に送られることはありません。個人で独立して開発しており、寄付は新機能やメンテナンスの時間になります。役に立ったら、コーヒーを一杯おごってください。
