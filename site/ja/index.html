メモを、画面の端に。

マウスを画面の右端に動かすと、メモがすっと現れます。離れれば、すっと消えます。Windows 用・無料。

Windows 版をダウンロード Microsoft Store — 近日公開

Sill Note · 無料 · Windows 10 / 11 · アカウント不要

メディア

画像も、音声も、YouTube も。ひとつのメモに。

画像をドラッグ、音声ファイルをドロップ、YouTube のリンクを貼り付け。すべてテキストの隣、メモの中に収まります。

ボイスメモ

話すだけ。もう保存済み。

ワンクリックで録音開始、波形がリアルタイムで動きます。録音中にマイクの切り替えも可能。止めた瞬間にマイクはオフになります。

整理

2 段のタブ。カラーで。

上にトピック、左にメモ。色分け、名前の変更、並べ替えも自由自在。ライトとダークのテーマ付き。

プライバシー

あなたのメモは、あなただけのもの。

アカウントもクラウドも追跡もなし。すべてあなたのパソコンに保存されます。プライバシーポリシーを読む

知っておくと便利なこと

「Windows によって PC が保護されました」と表示される

直接ダウンロード版はまだ署名されていないため、初回のみ警告が表示されます。詳細情報 → 実行 をクリックしてください。今後公開予定の Microsoft Store 版は Microsoft の署名付きで、この警告は表示されません。

どうやって開くの？

マウスを画面右端の中央に置くか、Ctrl + Alt + N を押します。ショートカットは設定で変更できます。

インターネットに接続しますか？

YouTube のリンクを貼り付けたときだけです。動画のサムネイルとタイトルを一度だけダウンロードします。設定 → プライバシーでオフにできます。
