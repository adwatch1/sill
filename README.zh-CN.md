## 功能

- **边缘触发。** 将鼠标停在屏幕右边缘中间，或按 `Ctrl + Alt + N`。
- **两级标签页。** 主题在上，笔记在左。可着色、重命名、拖动排序。
- **自动保存。** 没有保存按钮。
- **图片。** 拖放、用 `Ctrl + V` 粘贴，或右键 → 添加图片。
- **音频与语音笔记。** 拖入音频文件，或用麦克风录音并实时显示波形。
- **YouTube 卡片。** 粘贴 YouTube 链接，自动变成带缩略图和标题的卡片。
- **10 种语言。** 自动跟随 Windows 语言。
- **屏幕共享时隐藏。** 打开一个开关，Sill Note 就不会出现在屏幕录制、屏幕共享（Zoom、Teams、Discord、OBS）和截图中，而你自己仍能看到。
- **不透明度。** 让面板背景变透明（60–100%），文字和图片依然清晰。
- **专注视图。** 用侧栏按钮隐藏笔记列表，让笔记铺满整个面板。
- 浅色 / 深色主题、固定面板、可调宽度、开机启动。

## 安装

从 [Releases](../../releases/latest) 下载 `SillNote-Setup.exe` 并运行（无需管理员权限）。直接下载的安装包暂未签名，首次运行时 Windows 可能会提示：**更多信息 → 仍要运行**。由 Microsoft 签名并可自动更新的 Microsoft Store 版本即将上架。 不想安装？下载便携版 [ZIP](https://github.com/adwatch1/sill/releases/latest/download/SillNote-Portable.zip)，解压到任意位置后运行 `Sill.exe`。

## 隐私

你的笔记、图片、音频和设置只保存在你的电脑上。Sill Note 只在一种情况下联网：粘贴 YouTube 链接时，下载一次该视频的缩略图和标题（可在 设置 → 隐私 中关闭）。麦克风只在录音时使用。[隐私政策](https://www.sillnote.store/privacy.html)
